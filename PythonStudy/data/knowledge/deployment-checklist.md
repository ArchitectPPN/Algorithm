# 部署检查清单

## 部署前检查

- 代码已过评审，测试全绿，无遗留 TODO
- 配置项通过环境变量注入，不硬编码在代码里
- 数据库迁移脚本已准备好，且有回滚方案
- 新增的第三方依赖已记录到 requirements.txt / lock 文件

## 环境配置

- 开发/测试/生产环境配置隔离，生产禁止开 DEBUG
- 数据库、Redis 等连接串不写死，从配置中心读取
- 密钥（API key、JWT secret）走专门的密钥管理，不进配置仓库
- 环境变量默认值要安全：生产环境缺变量要启动失败而不是降级

## 发布流程

- 使用蓝绿或金丝雀发布，避免全量一刀切
- 发布窗口选择低峰期，回滚窗口内密切监控
- 记录发布版本号，便于快速定位和回滚
- 发布后验证：健康检查接口 + 核心业务冒烟测试

## 部署后监控

- 检查应用日志有无新增 ERROR
- 观察 CPU、内存、QPS、错误率、延迟曲线
- 告警规则要覆盖：服务不可用、错误率突增、资源打满
- 预留磁盘、日志归档，防止磁盘写满

## 回滚预案

- 明确回滚步骤和责任人，回滚要快（分钟级）
- 数据库迁移不支持回滚时，提前做兼容双写方案
- 回滚后验证数据一致性，必要时人工核对
- 事故复盘：记录时间线、根因、改进措施
