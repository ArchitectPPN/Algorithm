# Python 学习练习

本目录存放 Python 学习过程中的练习代码（2026年7月，Python 初学阶段）。

## 目录结构

```
learning/
├── README.md
├── exercises/              # 入门示例和小练习
│   ├── HelloWorld.py
│   └── Dog.py
└── python-basics/          # Python 基础语法练习
    ├── control-flow/       # 控制流（if/for/while）
    ├── data-types/         # 数据类型（字符串/列表/字典）
    ├── functions/          # 函数（def/参数/返回值）
    ├── oop/                # 面向对象（class/对象）
    ├── exceptions/         # 异常处理（try/except）
    └── file-io/            # 文件操作
```

## 学习顺序建议

1. **HelloWorld.py** - 第一行 Python 代码
2. **control-flow/** - if/for/while
3. **data-types/** - 字符串/列表/字典
4. **functions/** - def/参数/返回值
5. **oop/** - class/对象
6. **exceptions/** - try/except
7. **file-io/** - 文件读写
