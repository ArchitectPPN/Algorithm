# TUI 是什么

> Text-based User Interface，文本用户界面。也叫 Terminal User Interface（终端用户界面）。

---

## 一句话定义

**TUI = 长在终端里的"伪图形界面"**——没有图片，完全靠 ASCII/Unicode 字符、颜色和方框"画"出窗口、按钮、菜单，支持键盘（甚至鼠标）交互。

---

## 三种界面形态对比

| 类型 | 全称 | 特点 | 例子 |
|------|------|------|------|
| **CLI** | Command Line Interface | 纯文本输入输出，一行接一行 | `bash`、DOS |
| **TUI** | Text-based UI | 终端里的"伪图形界面"，字符画窗口 | `htop`、`vim`、`ranger` |
| **GUI** | Graphical UI | 窗口、按钮、鼠标、图标 | Windows/macOS 软件 |

TUI 介于 CLI 和 GUI 之间——比 CLI 直观，比 GUI 轻量。

---

## 常见的 TUI 例子

- **`htop`**（系统进程管理）：彩色进度条，方向键选进程，F9 杀进程
- **`vim` / `nano`**（文本编辑器）：菜单栏、分屏、光标高亮
- **`ranger`**（文件管理器）：终端里的资源管理器

---

## AI Agent 中的 TUI

启动 Pi Agent、Claude Code 等工具的交互模式时，看到的是**常驻全屏界面**，而不是一问一答的纯命令行。通常包含：

1. **输入框**：底部专门打字输入
2. **聊天区域**：上方实时流式显示 AI 回答，**不同颜色高亮**工具调用（读文件、搜索网页）
3. **状态栏**：思考状态、上下文长度、Token 消耗、耗时

---

## 为什么 AI 工具喜欢用 TUI

- **交互感强**：实时看到 AI 的思考过程和工具执行状态
- **轻量高效**：不像浏览器占用大量内存和 CPU，适合 SSH 远程服务器
- **键盘流友好**：开发者手不离键盘，Tab/方向键快速操作

---

## 一句话总结

> **TUI 就是给终端"化妆"，让它变身为一个精致的小型应用程序。**

把 `htop` 里的"CPU 核心"换成"AI 工具链"，就是 AI Agent 的 TUI 界面。
