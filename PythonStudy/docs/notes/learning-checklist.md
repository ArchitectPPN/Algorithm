# 学习检验标准

> 学习效果 = 能说清楚 + 能写出来 + 能回答追问。三者缺一不可。

---

## 检验三步法

每学完一个模块，必须通过以下三步检验：

### 1. 默写代码

**关掉所有文件，新建空白文件，凭记忆写出来。**

- 写不出 → 说明只是"看过"，不是真懂
- 卡住了 → 可以看原代码，但标记为"需复习"
- 流畅写出 → 通过

### 2. 一句话讲清楚

**对着空气（或手机录音），用不超过三句话解释核心概念。**

- 说得磕磕绊绊 → 理解不够深
- 能用小白都能懂的话说清楚 → 通过
- 能举例 → 优秀

### 3. 回答追问

**给自己提一个问题，看能不能答上来。**

| 追问模板 | 示例 |
|---------|------|
| "为什么要用 X 而不是 Y？" | 为什么要用 Agent 调用而不是直接调用？ |
| "如果不这样做会怎样？" | 如果不设 max_tokens 会怎样？ |
| "这和你之前学的 PHP 有什么关系？" | LangChain 和 Laravel 的异同？ |

## 按模块的检验清单

### LangChain 三种调用方式

- [ ] **默写**：直接调用 `model.invoke()`
- [ ] **默写**：Chain 调用 `prompt | model` + `chain.invoke()`
- [ ] **默写**：Agent 调用 `@tool` + `executor.invoke()`
- [ ] **一句话**：三种调用方式的本质是什么？
- [ ] **追问**：Agent 调用和直接调用的区别？

### Token 计算与上下文管理

- [ ] **默写**：`estimate_tokens()` 函数（tiktoken + 系数）
- [ ] **一句话**：为什么需要事前估算？
- [ ] **追问**：为什么 1.3 系数是"经验值"而不是"精确值"？
- [ ] **追问**：上下文 128K 指的是什么？字符数还是 token 数？

### Git Agent

- [ ] **默写**：ReAct 循环的核心逻辑
- [ ] **一句话**：ReAct 循环的四个步骤
- [ ] **追问**：如果模型调了不存在的工具怎么办？
- [ ] **追问**：为什么要用 system prompt 约束模型？

### LLM 适配器

- [ ] **默写**：`OpenAIAdapter.chat()` 的核心结构
- [ ] **一句话**：适配器解决了什么问题？
- [ ] **追问**：AnthropicAdapter 和 OpenAIAdapter 的区别？

---

## 通过标准

| 检验项 | 标准 |
|--------|------|
| 默写代码 | 能写出核心逻辑，语法细节可以查 |
| 一句话讲 | 流畅、准确、有例子 |
| 回答追问 | 能答出核心点，不需要完美 |

**三个都通过才算真正学会。** 缺任何一个，说明这个模块需要复习。

---

## 使用方法

1. 学完一个模块后，立即做检验
2. 检验不通过，标记为"需复习"，第二天重新检
3. 每周复盘时，把本周所有模块快速过一遍追问
