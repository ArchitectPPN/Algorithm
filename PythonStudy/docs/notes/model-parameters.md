# LLM 模型参数详解

> Agent 开发中常用的模型参数：temperature、top-p、max_tokens 等。
> 理解这些参数对 Agent 行为控制至关重要。

---

## 一、Temperature（温度）

### 一句话总结

**控制模型回答的"创造性/随机性"。值越高越天马行空，值越低越确定保守。**

### 原理

模型生成每个词时，会计算所有可能词的概率分布：

```
"我" → 0.5
"你" → 0.3
"他" → 0.1
"它" → 0.05
```

temperature 通过公式 `概率^(1/temperature)` 调整这个分布：

| temperature | 效果 | 概率分布 |
|-------------|------|---------|
| 0 | 选概率最高的（确定性） | 只选 "我" |
| 0.5 | 稍微发散 | "我" 概率更高，偶尔选 "你" |
| 1.0 | 正常 | 原始概率分布 |
| 1.5 | 更有创造力 | 低概率词也常被选中 |
| 2.0 | 几乎随机 | 所有词概率差不多 |

### 实际例子

**Prompt**：`"写一句关于AI的话"`

- **temperature=0**（每次都一样）："人工智能正在改变世界。"
- **temperature=0.7**（略有变化）："AI 技术日新月异，给人类带来无限可能。"
- **temperature=1.5**（天马行空）："AI 像一只会飞的猫，在数据的海洋里冲浪。"

### Agent 开发中怎么用

| 场景 | temperature | 原因 |
|------|-------------|------|
| **Agent 工具调用** | 0 | 必须精确选择工具，不能乱选 |
| **代码生成** | 0-0.2 | 需要确定性 |
| **JSON 输出** | 0 | 格式不能出错 |
| **创意写作** | 0.7-1.0 | 需要多样性 |
| **头脑风暴** | 0.8-1.2 | 需要发散思维 |

**Agent 开发基本都用 0**——你希望模型精确地决定"该调哪个工具、传什么参数"，而不是随机乱猜。

### 常见误区

- ❌ "temperature=0 是最优的" → 不对，创意场景需要高 temperature
- ❌ "temperature 影响速度" → 不影响，只影响概率采样
- ❌ "temperature 越大越聪明" → 太高会胡言乱语

## 二、Top-p（核采样）

### 一句话总结

**控制模型从概率最高的前 N% 词中选择。temperature 的替代方案，两者通常二选一。**

### 原理

```
词表概率分布：
"我" → 0.5  ✅
"你" → 0.3  ✅ (累计 0.8)
"他" → 0.1  ✅ (累计 0.9 > 0.9，停)
"它" → 0.05 ❌ (不选)
"猫" → 0.03 ❌
"狗" → 0.02 ❌
```

- **top-p=0.9**：只从概率累计到 90% 的词中选（"我""你""他"）
- **top-p=0.5**：只从概率累计到 50% 的词中选（"我""你"）
- **top-p=1.0**：所有词都可能被选

### temperature vs top-p

| | temperature | top-p |
|---|------------|-------|
| 调整方式 | 缩放概率分布 | 截断概率分布 |
| 效果 | 平滑调整 | 硬截断 |
| 使用场景 | 通用 | 需要精确控制候选词数量 |

**通常二选一**，不要同时调。

## 三、Max Tokens（最大输出长度）

### 一句话总结

**限制模型单次输出的最大 token 数（含推理和回答）。**

### 关键点

- 模型不会无限输出，达到上限会截断
- 设置太小：回答不完整
- 设置太大：浪费钱（但不会出错）
- Agent 工具调用场景：需要足够大的值（工具调用也占 token）

### 典型值

| 场景 | max_tokens |
|------|-----------|
| 简单问答 | 256-512 |
| 代码生成 | 1024-2048 |
| Agent 工具调用 | 2048-4096 |
| 长文生成 | 4096+ |

## 四、其他参数

### Frequency Penalty（频率惩罚）

**降低重复词的惩罚力度**。值越大，越不容易重复。

- -2.0 ~ 2.0
- 0 表示不惩罚
- Agent 开发通常用 0（不干预）

### Presence Penalty（存在惩罚）

**惩罚已经出现过的词**。值越大，越倾向于引入新话题。

- -2.0 ~ 2.0
- 0 表示不惩罚
- Agent 开发通常用 0（不干预）

### Stop（停止词）

**遇到指定词时停止生成**。

```python
stop=["\n\n", "Human:", "AI:"]
```

Agent 开发有时用，防止模型自己编对话。

## 五、Agent 开发推荐配置

```python
# Agent 工具调用场景
{
    "temperature": 0,        # 确定性，精确选择工具
    "top_p": 1.0,            # 不截断
    "max_tokens": 4096,      # 足够工具调用 + 回答
    "frequency_penalty": 0,  # 不惩罚
    "presence_penalty": 0    # 不惩罚
}

# 创意生成场景
{
    "temperature": 0.7,     # 有创造力
    "top_p": 0.9,            # 候选词更多
    "max_tokens": 2048,
    "frequency_penalty": 0,
    "presence_penalty": 0
}
```

## 六、面试要点

1. **temperature 控制随机性**：0=确定，1=正常，2=随机
2. **top-p 截断候选词**：只从概率最高的词中选
3. **Agent 开发用 temperature=0**：工具调用必须精确
4. **temperature 和 top-p 二选一**：不要同时调
5. **max_tokens 限制输出长度**：Agent 场景需要更大的值
