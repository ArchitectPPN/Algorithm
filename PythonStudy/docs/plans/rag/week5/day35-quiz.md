**2.** 余弦相似度的取值范围是 `[-1, 1]`。

**你的作答：**
> 正确，-1 代表完全不想等 1 代表完全相等； 但是印象中还有2的，可能我记混了。

✅ **参考解答（判断正确）**：对。`cos θ` 数学上必然在 `[-1, 1]`：`cos 0° = 1`（方向完全相同）、`cos 90° = 0`（正交无关）、`cos 180° = -1`（方向完全相反）。


**例子**：向量 `(1,0)` 和 `(0,1)` → 夹角 90° → 相似度 0，余弦距离 1；`(1,0)` 和 `(-1,0)` → 夹角 180° → 相似度 -1，余弦距离 2（最大值）。

### B1. 默写 `cosine_similarity(a, b)`

**你的作答：**
```python

```

❌ **参考解答（未作答）**：这题是 Day29 的核心产出，必须能默写。参考实现：

```python
import math

def cosine_similarity(a, b):
    """余弦相似度 = 点积 / (模长A × 模长B)"""
    dot = sum(x * y for x, y in zip(a, b))          # 点积：对应位置相乘求和
    mag_a = math.sqrt(sum(x * x for x in a))        # 模长A：各分量平方和开根号
    mag_b = math.sqrt(sum(x * x for x in b))        # 模长B
    return dot / (mag_a * mag_b)

# 例子验证：
print(cosine_similarity([1, 2, 3], [1, 2, 3]))     # 1.0  完全相同
print(cosine_similarity([1, 0], [0, 1]))            # 0.0  垂直无关
print(cosine_similarity([1, 2, 3], [-1, -2, -3]))   # -1.0 完全相反
```

**记忆锚点**：`cos(θ) = (A·B) / (|A||B|)`，三个步骤——点积、两个模长、相除。拆成三个函数（`dot_product` / `magnitude` / `cosine_similarity`）更好记。

### B4. 应用：带阈值过滤的 `search()`

**你的作答：**
> 我用的度量：
> 阈值怎么定的：（未作答）

❌ **参考解答（未作答）**：Day33 第五步的重点。参考实现（选**余弦**度量，理由见 C3）：

```python
def search(query, top_k=3, min_similarity=0.5):
    """语义检索 + 余弦阈值过滤"""
    results = collection.query(
        query_embeddings=[get_embedding(query)],
        n_results=top_k,                       # 先多取候选
        include=["documents", "metadatas", "distances"]
    )
    output = []
    for i in range(len(results["ids"][0])):
        cos_sim = 1 - results["distances"][0][i]   # 余弦距离 → 余弦相似度
        if cos_sim < min_similarity:               # 不相关，丢弃
            continue
        output.append({
            "content":    results["documents"][0][i],
            "file":       results["metadatas"][0][i]["file"],
            "similarity": cos_sim,
        })
    return output
```

**阈值怎么定（Day33 讲的 3 种方法，选哪种）**：

| 方法 | 原理 | 何时用 |
|------|------|--------|
| **① 经验值 0.5** | 余弦相似度 < 0.5 基本不相关 | 快速起步，我选它——知识库小、够用 |
| **② Elbow 拐点法** | 把候选按距离排序，找"急剧上升"的拐点 | 无标注数据时 |
| **③ 已知答案校准** | 用已知该命中的查询，看相关/不相关的距离分界 | 有标注答案时更准 |

**例子论证（来自我们项目的实际数据）**：查询「Python 变量命名规范」，相关结果距离约 210，不相关约 329——用已知答案校准法，阈值定在 300~350 之间；或直接用余弦 0.5 起步，简单可跨项目复用。

### C3. L2 vs 余弦，为什么 RAG 推荐余弦？何时等价？

**你的作答：**
> 这个我不记得了，我需要再记忆下。

❌ **参考解答（Day33 第六步核心，必须补）**：

**推荐余弦的 3 个理由**：

1. **对文本长度不敏感**：余弦只看**方向**不看**大小**。知识库片段长短不一（有的 100 字有的 500 字），L2 会受向量长度影响。

   **例子论证**：同一句话「我喜欢编程」，长版 500 字 vs 短版 5 字，语义完全相同，但向量**长度**不同——L2 距离可能差很远，余弦相似度却很接近。

2. **阈值可通用**：余弦相似度固定 `[-1, 1]`，**0.5 是跨项目可复用的经验值**；L2 无上界，换模型/换文档就要重新校准（回到 A1.4）。

3. **语义方向才重要**：文本检索关心"这句话是不是在说同一个意思"，不关心"向量绝对值多远"。

**何时等价**：**embedding 向量已归一化**时（模长为 1），L2 和余弦排序结果完全等价——因为此时 L2 距离只是余弦距离的单调函数。**nomic-embed-text 输出就是归一化的**，所以我们项目里两种度量的排序基本一致，差异主要体现在**阈值的可操作性**上。

**对比表（记忆）**：

| | L2 距离 | 余弦相似度 |
|---|--------|-----------|
| 公式 | √(Σ(aᵢ−bᵢ)²) | (A·B)/(|A||B|) |
| 范围 | [0, +∞) 无上界 | [-1, 1] 固定 |
| 受向量长度影响 | ✅ | ❌ |
| 阈值 | 需逐项目校准 | 0.5 可复用 |

### C4. 固定阈值的问题 + 工程解法？

**你的作答：**
> 首先，固定距离阈值不适合所有场景的内容，如果所有的场景都使用同一套机制，那么就会导致检索的结果可能包含你不想要的内容，语义上接近，但是和问题不相关。工程上怎么做，是我欠缺的内容。

⚠️ **参考解答（答到问题的一半，解法没答）**：

**固定阈值的问题有两个**（你只答了其一）：

1. **(你答了) 纯距离过滤是数学近似**：距离小 ≠ 一定相关，语义上接近但答非所问的内容会被误放进来。
2. **(你没答) L2 无上界**：换模型/换文档阈值就失效，不能跨场景复用（A1.4/C3 的同源知识点）。

**工程解法：两层过滤**：

```
检索结果(1000条) → 第一层粗筛 → 候选(5-10条) → 第二层精筛 → 最终(2-3条)
```

- **第一层（粗筛，便宜快）**：余弦相似度 > 0.5，把候选从 1000 压到 5-10 条，过滤明显不相关的。
- **第二层（精筛，准但贵）**：把候选片段交给 **LLM**，让 LLM 判断"这个片段是否真和问题相关"。

**例子论证**：搜「如何防止 SQL 注入」，粗筛后候选里可能混入一篇讲"密码存储"的（都涉及安全、语义相近），LLM 精筛能识别"用户问的是注入防护，不是密码哈希"，把不相关的剔掉——纯距离阈值做不到这层语义判断。

**关键认识**：距离是数学近似，LLM 才理解语义。**粗筛控制成本，精筛保证准确**，两者组合。

```python
class RAGPipeline:
    def __init__(self, ...):
        ...
        self._embed_cache: dict[str, list[float]] = {}

    def _embed(self, text: str) -> list[float]:
        if text in self._embed_cache:
            return self._embed_cache[text]           # 命中缓存，省一次 API
        resp = requests.post(

        return vec
```
